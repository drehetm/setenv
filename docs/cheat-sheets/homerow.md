# `Homerow` - cheat sheet

#### `Karabiner-Elements` key mappings
* `<Caps Lock>` - maps to `Hyper Key` (`<Escape>` if alone)
* `<Caps Lock> + h/j/k/l` - maps to `Arrow Keys`

## Common key combinations
1. `<Caps Lock> + F` - activate `Click Mode`
2. `<Caps Lock> + D` - activate `Search Mode`
3. `<Caps Lock> + A` - activate `Scrolling Mode`
* `<Esc>` - exit from `ANY` mode

### Click types in `Click/Search` modes
1. `<Return>` - left click on the focused UI element
2. `<Shift> + <Return>` - right click
3. `<Command> + <Return>` - open link in new tab (== `<Command> + left_click`)

## Click Mode
* `<Space>` - left click

## Search Mode
1. Focus UI element:
    - `<Caps Lock> + j/k` - press until the correct UI element is focused
    - `<Shift> + label_text` - jump directly to UI element
3. `?` - invoke Tutor for the focused UI element

## Scrolling Mode
1. Choose/Activate scroll area:
    - `<Caps Lock> + j/k` - next/previous scroll area
    - `0-9` - choose scroll area by its number
3. Scroll active area:
    - `h/j/k/l` - scroll
    - `Shift + h/j/k/l` - `jump` through area
    - `d/u` - half page down/up
    - `gg/G` - go to top/bottom
